# Hannahmani Portfolio Website
## Project Description
This is a colorful and accessible personal portfolio website developed using HTML5, CSS3, and JavaScript.
The project follows modern semantic HTML5 structure and WCAG accessibility guidelines to create a responsive and user-friendly website.
---

## Features
- Semantic HTML5 Structure
- Responsive Design
- Accessibility Support
- SEO Friendly Meta Tags
- Dark Mode Feature
- Keyboard Navigable Website
- Contact Form
- Modern Colorful UI
- Sidebar Profile Section
---

## Technologies Used
- HTML5
- CSS3
- JavaScript
---

## Accessibility Features
- ARIA Labels
- Semantic Tags
- Focus Indicators
- Accessible Form Fields
- Responsive Layout
---

## Project Sections
- Home
- About
- Projects
- Contact
---

## How to Run the Project
1. Download the project files
2. Open the folder in Visual Studio Code
3. Install Live Server Extension
4. Right Click on `index.html`
5. Click "Open with Live Server"
